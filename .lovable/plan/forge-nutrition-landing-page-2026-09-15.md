# FORGE Nutrition Landing Page

## Goal
Build one polished, responsive nutrition and gym-products landing page in the selected Clay 3D Athletic style.

## Page structure
- Sticky compact header with FORGE branding, section links, and bag action.
- Auto-running three-message campaign banner using the generated supplement artwork.
- Horizontally scrollable category choices for Protein, Creatine, Pre-Workout, Vitamins, Gummies, and Bundles.
- Six-product storefront grid: three columns on wide screens and a compact two-column layout on phones.
- Dark Instagram-style reel band with continuously moving vertical visuals.
- Auto-running verified customer-rating carousel.
- Structured footer with shop, company, support, newsletter, and social links.

## Visual direction
- Preserve the chosen deep teal, warm amber, cream, clay, and ink palette.
- Use Archivo for bold display type and DM Sans for body text.
- Use generated clay-style product and fitness artwork throughout.
- Keep corners controlled, spacing clean, and interactions restrained rather than overly animated.

## Behavior and responsiveness
- Banner, reels, and ratings move automatically and pause on hover.
- Respect reduced-motion settings.
- Prevent clipping and overlap at phone widths; product names, prices, and actions remain readable.
- Navigation and calls to action scroll to relevant sections on this single page.

## Technical details
- Implement with the existing React/TanStack page and Tailwind CSS design tokens.
- Add semantic button variants for the selected storefront style.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Verify the completed page in desktop and mobile browser sizes, including animation layout and image loading.
